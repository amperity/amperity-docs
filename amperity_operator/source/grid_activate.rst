==================================================
Activate your data
==================================================

.. grid_activate-about-start

Send audiences and customer profiles from Amperity to the platforms and applications that act on them: campaigns and destinations, tables shared back to your data warehouse through Amperity Bridge, and profiles that applications read from the `Database Profile API <explorer-database-profile-api_>`__.
