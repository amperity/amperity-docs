About the Tenant API
==================================================

.. start-here-start

The Tenant API enables programmatic access to your Amperity tenant by using a collection of RESTful endpoints that support API-first use cases for integrations, applications, and custom workflows. Use Tenant API endpoints to streamline workflows, enhance marketing strategies, and unlock the value of your brand's customer data.

.. start-here-end


.. _index-openapi-specification:

OpenAPI specification
==================================================

.. start-here-openapi-specification-start

Amperity publishes an OpenAPI specification for each of its APIs. Browse and try them on the :doc:`Amperity APIs <explorer>` page. Download an OpenAPI specification from that page, and then import it into an API tool, such as `Postman <https://www.postman.com/>`__, to start interacting with Tenant API endpoints.

.. start-here-openapi-specification-end
