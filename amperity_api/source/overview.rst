Overview
==================================================

.. api-amperity-start

The Tenant API enables programmatic access to your Amperity tenant through a collection of RESTful endpoints that support API-first use cases for integrations, applications, and custom workflows. Use Tenant API endpoints to streamline workflows, enhance marketing strategies, and unlock the value of your brand's customer data.

.. api-amperity-end

.. api-amperity-openapi-and-postman-start

.. admonition:: OpenAPI and Postman

   Amperity publishes an OpenAPI specification for each of its APIs. Browse and try them on the `Amperity APIs <https://docs.amperity.com/api/explorer.html>`__ page. Download an OpenAPI specification from that page, and then import it into an API tool, such as `Postman <https://www.postman.com/>`__, to start interacting with Tenant API endpoints.

.. api-amperity-openapi-and-postman-end
