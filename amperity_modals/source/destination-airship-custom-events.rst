Airship Custom Events
==================================================

Send |what-send| to |destination-name| so that customer behavior in Amperity can trigger an |destination-name| automation and personalize the message it sends. Each row returned by your query is sent as a single |destination-name| custom event.

.. events-airship-custom-events-modal-beta-start

.. admonition:: Beta

   The Airship Custom Events connector is currently in beta. Contact your Amperity representative to learn more.
