Amazon Ads Conversion API
==================================================

Send conversion events to |destination-name| using the Amazon Ads Conversion API (CAPI) to measure return on ad spend (ROAS), attribute offline conversions to Amazon DSP campaigns, and enrich audiences with first-party data.
