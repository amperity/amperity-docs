.. A notice for a page that documents a legacy feature: one that still works but
.. has been replaced. Put it directly under the page title, and add |legacy| to
.. the title. Define these three substitutions on the page before the include:
..
..    .. |legacy-feature| replace:: The Streaming API
..    .. |legacy-replacement| replace:: Real-time Profiles
..    .. |legacy-instead| replace:: For new integrations, use the `Real-time API <...>`__ instead.
..
..    Then include the notice chunk below. The contributing guide's
..    "Legacy features" section has the exact include directive. (It is not
..    repeated here: a copy of the chunk markers in this comment would be
..    matched first, and the include would pick up the comment instead.)
